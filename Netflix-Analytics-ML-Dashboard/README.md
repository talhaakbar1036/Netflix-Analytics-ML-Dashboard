# Netflix Data Science Internship Project — Auspify Technologies

Full solution to all 6 tasks from the Auspify Technologies Data Science Internship
task list, built on the Netflix titles dataset (8,790 rows).

## Project Structure

```
netflix_ds_internship/
├── main.py                              # Runs all tasks end-to-end
├── data/
│   ├── netflix_dataset.csv              # Raw input dataset
│   └── netflix_cleaned.csv              # Generated by Task 1
├── tasks/
│   ├── task1_data_cleaning.py           # Task 1 (Easy)
│   ├── task2_eda.py                     # Task 2 (Easy)
│   ├── task3_recommendation_system.py   # Task 3 (Medium)
│   ├── task4_trend_prediction.py        # Task 4 (Medium)
│   ├── task5_classification_model.py    # Task 5 (Advanced)
│   └── task6_business_dashboard.py      # Task 6 (Advanced)
└── outputs/
    ├── task1/ ... task6/                # Reports + charts per task
```

## How to Run

Run everything (all 6 tasks, in order):
```bash
python3 main.py
```

Run only specific tasks (e.g. Task 2 and Task 5):
```bash
python3 main.py --tasks 2 5
```

Run a single task directly:
```bash
python3 tasks/task2_eda.py
```

Each task can also be imported and called from Python:
```python
from tasks.task2_eda import run
results = run()
```

## Task Summaries

| # | Task | Difficulty | What it does |
|---|------|-----------|----------------|
| 1 | Data Cleaning & Preprocessing | Easy | Loads raw CSV, fixes the `"Not Given"` placeholder, parses dates, splits `duration`, saves `netflix_cleaned.csv` |
| 2 | Exploratory Data Analysis | Easy | Movie vs TV Show split, top countries/genres/ratings, release-year trends, 4-panel dashboard chart |
| 3 | Recommendation System | Medium | TF-IDF + cosine similarity over genre/director/type, generates top-5 recommendations, evaluates via genre-overlap |
| 4 | Trend Prediction | Medium | Linear regression forecast of content releases for 2022–2026, historical vs forecast chart |
| 5 | ML Classification Model | Advanced | Logistic Regression / Decision Tree / Random Forest to classify Movie vs TV Show; confusion matrix, feature importance, model comparison |
| 6 | Business Insights Dashboard | Advanced | Combines EDA + forecasting + classification into one 6-panel dashboard plus a written business-recommendations report |

## Notes

- Internship rules require completing **any 4 of 6** tasks — this project completes **all 6**.
- Task 5's classifier hits ~99.9% accuracy mainly because `duration_value` is measured
  in different units per class (minutes for Movies, seasons for TV Shows) — this is
  flagged in the script output/report as a near-leaky feature, not overstated as a
  "real" result.
- All outputs (text reports + PNG charts) are saved under `outputs/taskN/` so they can
  be attached directly to the internship submission.
